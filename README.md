# Product Store

A web-based product store application built with Vite and Node.js. The project demonstrates frontend and backend development for a product management application.

## Technologies

- JavaScript
- Vite
- Node.js

## Key Features

- Product listing and management
- Backend API integration
- Dynamic frontend interface

## Getting Started

1. Clone the repository.
2. Install dependencies.
3. Configure environment variables if required.
4. Start the application using the available development scripts.
